# 为什么 tz 需要人工微调 50mm？—— 从诊断到结论的完整推导

> 配图：`docs/fig1_pinhole_ranging.png` ~ `fig4_error_chain.png`（`make_tz_figs.py` 生成）
> 数据：`solve_range_bias.py` 对 15 帧 20260918 数据的实测

## 1. 问题

16 帧标定的裸解给出 `t = [0.029, 0.060, +0.040]`，但目测评判需要 `tz −50mm`
（`tz: +0.040 → −0.010`）才是正确结果。**5cm 的系统差从哪来？为什么每次微调都落在 tz 上？**

## 2. tz 在标定里是怎么算出来的

```
相机侧:  棋盘格角点 → solvePnP → 板中心 center_cam（含深度 Z）
雷达侧:  segment_board → 板中心 center_lidar
求解:    t = mean( center_cam − R·center_lidar )   ← 逐帧取均值
```

关键事实：**这个差值 = 两个独立传感器对同一物理点（板中心）的测距差**。
任何一侧存在系统性的"测距偏置"，都会原样填进 t，而三个分量里 tz（深度方向）
是测距偏置的直接落点 —— 这就是微调总落在 tz 的原因。

## 3. PnP 是怎么"测距离"的（图1 `fig1_pinhole_ranging.png`）

针孔模型 + 相似三角形：

```
w [px] = fy · W / Z    →    Z = fy · W / w
```

| 量 | 来源 | 精度 |
|---|---|---|
| w（板的像素尺寸） | 图像直接测量 | 准（角点检测 ~0.5px）|
| W（板的物理尺寸） | **假设值**（格距 120mm × 格数）| 取决于板制造精度 |
| fy（焦距） | **标称内参** | 取决于出厂标定 |

**Z_pnp 的相对误差 = W 的假设误差 + fy 的标称误差**（相加）。

## 4. 核心原理：尺度吸收 —— 为什么所有自动判据都看不见它（图2）

solvePnP 最小化的是**角点重投影的像素残差**。但给定同一组角点像素，(W, Z) 是
**尺度不确定**的：

```
Z_est = (W_假设 / W_真实) · Z_true
```

PnP 的 6 个自由度里，"距离"这个自由度会把尺度误差**完全吸收**掉：角点照样拟合到
<1px，重投影 RMS 漂亮 —— **但板被推远了 3.4%**。

推论：
- 一切只基于角点/重投影残差的判据（PnP 自身、图像残差 |Δ|、落格率）**结构上无法发现此偏差**
- 雷达侧（ToF/直接测距）不依赖"目标尺寸假设"，天然免疫 —— 所以偏置必在相机侧

## 5. 诊断实验：同原点、同物点、绕过外参 t（图3）

设计：找一个**不经外参 t** 的独立测距基准 —— Orbbec 相机的**深度点云**。
对每帧：

```
Z_pnp   = PnP 解出的板中心深度（吃 fy 与板尺寸假设）
Z_depth = 深度云在板框像素处的 Z 中位数（独立物理测量，同为相机原点）
Δ_cam   = Z_pnp − Z_depth
```

实测（15 帧）：

```
Δ_cam 中位 = +54.2 mm,  σ = 28 mm
旁证: r_lidar − Z_depth ≈ 2~4 cm ≈ LiDAR-相机基线投影 → 雷达侧尺度干净
```

**结论：相机侧（PnP 测距）系统性偏远 ~54mm，实锤。**

## 6. 误差闭环：人眼微调 ≈ 深度测量（图4）

```
PnP 偏远 +54mm
  → 求解时 t 吸收 +54mm（把雷达云整体放远 54mm 去迁就 PnP）
    → colored 渲染：点云深度方向偏远 54mm，颜色错位
      → 人眼调 tz −50mm 拉回  ←→  −50mm ≈ −54mm ✓ 闭环吻合
```

人眼在不知情的情况下完成了与深度测量等价的补偿 —— 这也是"目测才是最终判据"
的正确性来源。

## 7. 根因二选一：板尺寸 vs 焦距

`Z_est ∝ W_假设` 且 `Z_est ∝ fy`，单看 Δ 无法区分：

| 假设 | 含义 | 修复方式 |
|---|---|---|
| A. 板实际格距 **116mm**（标称 120 是印刷/标称误差）| W 被高估 120/116 = 3.45% | 改 `SQUARE_SIZE_M = 0.116` 重解 |
| B. 板确实是 120mm，**fy 标称偏大约 3.4%** | 内参出厂标定偏差 | fx/fy ×0.966 重解 |

**一尺子量一格棋盘即可判定**（量中间格，精确到 mm）。

## 8. 假设格子 = 116mm 的完整误差推演

设定：真实格距 116mm，PnP 仍按 120mm 建模型点。

**① 真实几何**（板 5×7 格）：板宽 W_true = 5×0.116 = 0.580 m。
图像里角点间距 w 由真实板在真实距离处决定：

```
w = fy · 0.580 / Z_true
```

**② PnP 解算**（以为是 120mm）：模型板宽 W_assumed = 5×0.120 = 0.600 m。
要解释同一个 w，解出的距离必须满足：

```
Z_pnp = fy · 0.600 / w = Z_true × 0.600/0.580 = 1.0345 · Z_true
```

**③ 数值代入**（取深度云中位 Z_true ≈ 1.546 m）：

```
Z_pnp = 1.546 × 1.0345 = 1.600 m
Δ     = +54 mm   ← 与 15 帧实测中位 +54.2 mm 几乎完全一致 ✓
```

逐帧核对：`Z_pnp/Z_depth` 分布在 1.03~1.07，中位 1.034 ✓
（散布来源：深度噪声、板倾斜时 Z 中位数定义差、个别帧角点质量）

**④ 误差如何流进外参**：

```
每帧相机侧板中心 Z 都偏远 +54mm
  → t = mean(center_cam − R·center_lidar) 的 tz 分量吸收 +54mm
    → 裸解 tz = +0.040（正确值应 ≈ −0.010）
      → colored 点云偏远 54mm
        → 人眼 tz −50mm 补偿（第 6 节闭环）
```

**⑤ 可验证的预测**：把 `SQUARE_SIZE_M` 改为 0.116 重跑标定：

- PnP 距离直接降 3.4% → 与深度云对齐 → **tz 微调需求应降到 ~0mm**
- 若预测成立，根因 A 坐实；若不成立（微调仍需 ~50mm），则根因 B（fy），改内参尺度重试

## 9. 结论

1. **tz 需要人工微调 = 相机侧存在 ~3.4% 的测距尺度系统偏差，被 t 的求解吸收所致**；
   它逃过所有角点/重投影类自动判据是"尺度吸收"的必然结果。
2. 根因是"板格距 116 vs 120"还是"fy 标称偏差 3.4%"，**一尺子量格子即可判定**。
3. 修正后预测：重解外参的 tz 与目测评判一致（微调 ≈ 0），colored 与深度云距离差 < 10mm。
4. 方法论沉淀：**双传感器"同原点同物点"测距对比**（`solve_range_bias.py`）能暴露一切
   被外参 t 吸收的系统偏差 —— 以后新数据集标定先跑它。
